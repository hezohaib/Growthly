How this is built
  • One state object. Every click changes state, then render() redraws only what depends on it.
  • Data comes from a seeded random generator, so numbers are the same on every load.
  • KPIs compare the selected period against the equal-length period before it.
  • The line chart is hand-built SVG: scale functions, a rounded axis maximum, and pointer-to-nearest-day hover.
  • The table filters, sorts and paginates in that order. Search is debounced and keeps input focus.
  • Plain HTML, CSS and JavaScript. Keyboard and screen-reader friendly, light and dark themes.
